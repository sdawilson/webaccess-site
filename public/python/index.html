A minute and a half, with narration and captions: modern VBA, the libraries in References, a Python module called from VBA, a form passed to Python, a Matplotlib chart on a form, and JavaScript.

Python modules, called from VBA

Insert > Python Module puts a Python module beside the VBA ones. Its functions are called from VBA by name: Debug.Print Summary.describe(Array(14, 18, 21)).

  • Real Python (3.14), not a lookalike, with its standard library
  • Tick the libraries a database uses in References: pandas, NumPy, Matplotlib, SciPy, scikit-learn and Pillow
  • A VBA array arrives as a list, and a recordset as its rows
  • Return a tuple and VBA gets an array; return a dict and it gets JSON
  • A Python error stops the VBA as a run-time error, with Python's message and line
  • Python colouring, indenting and a compile check in the code window

Pass it a form, and it changes the form

One line of VBA in an event passes the form to Python: OrderMaths.line_summary Me. Python reads the form and sets what it wants changed.

  • The form's controls, the current record, and the rows a subform shows
  • Set a caption, a colour, a value or whether a control is locked
  • Reports too, from a section's Format event, with a subreport's records
  • A recordset passed in arrives as its rows, ready for pandas

The form goes to Python as a copy. What Python changes is written to the real form when the function returns, so a Python function can't wait for a click.

Charts and pictures on a form

A Matplotlib figure or a Pillow image comes back to VBA as a picture, and an Image control's PictureData shows it.

  • Any chart Matplotlib draws, on the data your queries return
  • Pictures made or changed with Pillow
  • Shown when the form opens, or when a button is clicked

JavaScript too

JavaScript modules work the same way: write your own, or tick a library in References and call it from VBA.

  • Statistics, from means to linear regression
  • Dates: working days, UK bank holidays, ISO weeks and financial years
  • Fuzzy matching, for tidying names typed in different ways
  • British National Grid coordinates, CSV, and hashes and UUIDs
  • A form or report passed to JavaScript works as it does with Python

Good to know

Python here runs in the browser, so it works a little differently from Python on a server.

No network or files
Python and JavaScript run in a sandbox. They work on what VBA passes them, and can't reach the internet or your disk.
A few seconds to start
Python starts the first time it's called, then stays ready. Options can load it when the database opens.
On a computer
It works in Chrome, Edge, Firefox and Safari on a computer. Phones haven't been tested with the large libraries.
Copies, not live links
A form passed to Python goes as a copy, and changes are written back at the end. IntelliSense is for VBA; it isn't in Python modules yet.
