Worksheets on live data

The Spreadsheet control puts a workbook on a form. Lay it out as you would in Excel, with titles, formulas and formatting, then choose the row where the records of a table or query go.

  • Records are inserted at the row you choose. What's above and below them stays, and a total beneath stretches as records come and go
  • A formula beside the first record fills down, one for every record
  • Change a cell and its record is saved at once. Or turn Auto Update off, and your code decides when, with Data.Update
  • Allow Edits, Allow Inserts and Allow Deletes, set for each workbook
  • Lock the layout, so Users can change the records and nothing else
  • Link a workbook to the form's current record, the way a subform is linked
  • Import and export Excel files, with their formulas, formats and column widths
  • Excel's objects in VBA: Workbook, Worksheet, Range and ListObject, with SheetChange and SheetSelectionChange events
  • PivotTable and PivotChart views work from the same table or query

What carries over

You keep the worksheet, the formulas and the VBA. What changes is where the data lives: in a table, with rules, where everyone works on the same records.

What's different

It isn't Excel, and it's better to know where before you start.

A workbook lives on a form
You open a form, and the workbook is a control on it, beside any buttons, combo boxes or charts you add. There isn't a file to pass round.
One block of records on each sheet
A sheet takes the records of one table or query, at one place. Use more sheets, or more workbooks, for more.
Pivots and charts aren't drawn on the sheet
They're views and controls of their own, working from the same table or query, so they always show what the sheet shows.
The VBA in a workbook doesn't import
Paste it into the form's module. Code for cells and ranges mostly runs as written; code for charts, shapes, files on your PC or other applications needs changing.
Some things don't come with an imported file
Conditional formats, data validation, filters, charts and PivotTables. The first three can be set again in the workbook here.
There's no macro recorder
Macros are built in Macro Design, from a list of actions.

Start from a workbook

The usual route from a shared spreadsheet to something several people can rely on. Do it yourself, or tell the assistant what you need and look over its plan.

  1. Put the data in a table

    Import the sheet that holds your rows. Each column becomes a field with a type, and you can add rules for what it will accept.

  2. Put a workbook on a form

    Add a Spreadsheet control, then import your workbook as its layout, or lay one out from new.

  3. Point it at the table

    Choose the table or query, and the row where its records go. Formulas beside the first record fill down, and totals stretch.

  4. Share it

    Invite people by email, as a User or a Guest. They open it from the link, in the runtime, and up to 10 per database are free.

Questions

Is it Excel?

No. Web Access Builder is an independent product, and isn't made by or connected with Microsoft. Its Spreadsheet control is a workbook on a form, with several sheets, formulas and formatting, and it reads and writes Excel files. It doesn't do everything Excel does. Coming from Excel says what carries over and what doesn't.

Can I open my Excel workbook in it?

Yes, as a starting point. Importing a workbook brings in its values, formulas, number formats, fonts, fills, borders, column widths, merged cells and frozen panes. Conditional formats, data validation, filters, charts and PivotTables don't come with the file: set them up again here. The data itself is better moved into a table, which also imports from Excel.

Do my Excel macros run?

The language does, but the code doesn't import with the workbook. VBA written for Excel's Workbook, Worksheet and Range objects runs against a Spreadsheet control once you paste it into the form's module, with change events. It isn't the whole of Excel's object model, so expect to adjust code that uses charts, shapes, files on your PC or other applications.
