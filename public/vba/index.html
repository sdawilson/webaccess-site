What's different in a browser

It's VBA, but it isn't Windows. These are the things to know before you bring code across.

No Windows API
Declare statements and CreateObject for desktop applications have nothing to call in a browser. Dictionary and RegExp are built in.
Files are the browser's
Code can't read or write the disk directly. Imports and exports go through the browser's file picker and downloads.
Not Excel's whole object model
Workbook, Worksheet, Range and ListObject are there for the Spreadsheet control. Charts, shapes and other Office applications are not.
JavaScript when you want it
Where desktop code would call a DLL, write a JavaScript module and call its functions from VBA.

The Programmer's Guide lists what's supported, statement by statement, and Differences from Access lists what isn't.
